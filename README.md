# Vocabulary Quiz Games

A simple GitHub Pages-ready starter page for a future vocabulary quiz app.

## What is included

- A single static `index.html`
- A responsive, kid-friendly layout
- A tiny built-in quiz demo

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Set the source to the default branch and the root folder.
4. Save.
5. Open the provided GitHub Pages URL.
